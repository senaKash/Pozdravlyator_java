# Pozdravlyator_java

SPA веб-приложение для ведения списка дней рождения.

## Стек технологий

- Spring Boot
- Spring Data JPA
- PostgreSQL
- H2 (test profile)
- Swagger / OpenAPI
- JUnit 5

## Функциональность

- Просмотр всех ДР
- Просмотр сегодняшних ДР
- Просмотр ближайших ДР (с параметром days)
- Добавление
- Удаление
- Редактирование
- Загрузка и отображение фото
- Тесты

## Запуск

mvn spring-boot:run
